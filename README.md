# 森林学校 · 课间十分钟

浏览器里直接玩的**课间小游戏合集**，给小朋友做的。森林学校主题的第二个作品，和跑酷篇共用同一套角色 IP。

**在线玩：** <https://willzhan1983.github.io/forest-school-games/>

同系列跑酷篇：[forest-school-runner](https://github.com/willzhan1983/forest-school-runner) · <https://willzhan1983.github.io/forest-school-runner/>

---

## 三个小游戏

| 游戏 | 主角 | 玩法 |
|------|------|------|
| **接橡果** | 涂涂 Doodle（猫头鹰） | 橡果从树上往下掉，左右移动接住。连击越高单次加分越多（10 分起，每连击 +3，封顶 50），漏接扣一颗心 |
| **松鼠冲刺** | 钱钱 Fuzzy（灰白猫） | 障碍迎面而来：按冲刺**撞碎**它 +10 分，或者跳过去。撞上扣一颗心、倒退几米。跑得越远分越高 |
| **记忆翻牌** | 钱钱 + 涂涂 | 翻开卡片找相同的小动物。基础 1000 分，按用时和翻牌次数扣分，保底 50 分 |

每个游戏**独立记最高分**，难度也是每个游戏单独生效。

## 难度

| 难度 | 接橡果 | 松鼠冲刺 | 记忆翻牌 |
|------|--------|----------|----------|
| 简单 | 5 颗心 · 同屏最多 2 个 · 落得慢 | 5 颗心 · 障碍稀疏 | 4×3 = 12 张 |
| 普通 | 3 颗心 · 同屏最多 3 个 | 3 颗心 | 4×4 = 16 张 |
| 困难 | 2 颗心 · 同屏最多 4 个 · 落得快 | 2 颗心 · 障碍密集 | 6×4 = 24 张 |

难度选择在菜单页，选完会记住，下次打开还是它。

## 怎么玩

**电脑（键盘）**
- `1` `2` `3` 选游戏，`←` `→` 选难度，`空格` 开始
- 接橡果：`←` `→` 或 `A` `D` 移动
- 松鼠冲刺：`空格` / `↑` / `W` 跳跃，`D` / `Shift` / `→` 冲刺
- 记忆翻牌：鼠标点卡片
- 任何时候按 `Esc` 回菜单

**手机 / 平板（触屏）**
- 菜单页：点卡片直接开始，点难度条切换
- 接橡果：手指按住屏幕左右拖，涂涂跟着走
- 松鼠冲刺：点上半屏跳跃，点下半屏冲刺
- 记忆翻牌：点卡片

横屏玩最舒服，竖屏也能玩（会弹一条提示，4 秒后自己消失，不挡画面）。

## 其他

- 背景音乐在菜单页就响，一路延续到游戏和结算页不中断；左上角音符按钮随时开关，**开是绿底、关是灰底带红斜杠**，一眼能看出来
- 音乐开关和难度都记在本地，关掉网页下次还在
- 最高分也是本地记的（浏览器 localStorage），换设备不通用

## 技术

单个 `index.html`，**零外部依赖** —— 没有 CDN、没有库、没有图片文件，两个角色立绘以 base64 内联，断网也能玩。

- Canvas 2D 手绘全部画面（角色、背景、卡片、动物脸都是代码画的）
- Web Audio API 实时合成音效和 BGM（C 大调五声音阶，32 步 A/B 句，13.4 秒循环），没有音频文件
- 自动适配窗口大小和屏幕像素密度，键盘 + 触屏双套操作

> 浏览器规定声音必须由用户先点一下画面才能响，所以**打开页面后先点一下**，音乐就来了。这是所有网页游戏的共同限制，不是本游戏的问题。
